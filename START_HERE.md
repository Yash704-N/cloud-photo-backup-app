## ⚡ Run in 90 Seconds

### Step 1: Open Terminal
Navigate to project folder or right-click and open terminal here

### Step 2: Copy & Paste Command

**Windows**:
```
python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt && python app.py
```

**Mac/Linux**:
```
python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt && python app.py
```

### Step 3: Open Browser
Go to **http://localhost:5000**

- Click Register
- Create username & password
- Click Login

## ❓ Common Questions

**Q: I get "port already in use" error**  
A: Change port in app.py line ~520 from 5000 to 5001

**Q: Python not found**  
A: Install Python from python.org or use full path

**Q: Database error on first run**  
A: Delete database.db and restart app

**Q: Where are my uploaded photos?**  
A: Check `uploads/user_1/` folder

**Q: How do I deploy to production?**  
A: See INSTALLATION_GUIDE.md deployment section

**Q: Can I modify the code?**  
A: YES! It's yours to customize
